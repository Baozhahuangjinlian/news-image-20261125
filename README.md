make.fun bounty entry: Wednesday 25 November 2026 world news in one 1024x1024 image — 33 sourced stories, a UTC timeline and a date check

The image sums up Wednesday 25 November 2026 in one front page: a giant date masthead, a 7-slot UTC timeline, a BY THE NUMBERS strip, 3 big illustrated headlines plus 10 small illustrated secondaries (13 drawn cards, every one with a location header, a region tag, a CLAIM/CONFIRMED/OFFICIAL/REPORTED tag and a named source), a world map with numbered pins, an ALSO ON one-liner list to reach 33 stories, a DATE CHECK strip that names what was left out as other days' news, and a HOW THIS PAGE WAS CHECKED box. The lead story — Shenzhou-24 carrying Pakistan's first astronaut to Tiangong — is shown as a within-day arc: 00:18 lift-off, 03:56 docked, 06:45 aboard.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (standard library only) verifies `entry.png` is a whole 1024x1024 PNG under 1 MiB and copies it unchanged to the output directory, printing its byte count and sha256. The image itself was rendered offline with PIL by `compose.py` (not part of this repository); both runs of `main.py` write the same bytes.
